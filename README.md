# آیین‌نامه رانندگی

وب‌اپلیکیشن آموزشی آزمون آیین‌نامه رانندگی: برگه‌های اصلی، آزمون‌های تستی، تابلوها، مفاهیم و خط‌کشی‌ها.

## اجرا

```bash
npm install
npm run dev
```

سایر دستورها: `npm run build` · `npm run preview` · `npm test` · `npm run check`

## داده‌ها

داده‌های تایپ‌شده در `src/lib/data` قرار دارند و برای بازتولید از منبع اصلی‌شان:

```bash
npm run convert:data
```
